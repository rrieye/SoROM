# BigInt Modular Arithmetic Library

Цей проєкт містить реалізацію багаторозрядної модулярної арифметики на C++.

## Збірка та запуск

Виконайте в терміналі (у папці з кодом):
```bash
g++ -O3 BigInt.cpp tests.cpp benchmarks.cpp main.cpp -o bigint
```

Після успішної компіляції запустіть програму:
```bash
.\bigint.exe
```

## Бенчмарки та візуалізація діаграм

Функція runBenchmarks() (яка викликається у main.cpp) автоматично вимірює середній час виконання всіх арифметичних операцій у наносекундах. 

1. Генерація даних: Під час роботи програми всі результати автоматично експортуються у файл benchmark_results.csv.
2. Побудова діаграми: Для створення графіка на основі CSV-файлу використовується скрипт на Wolfram Language. Для його запуску виконайте:
```bash
wolframscript -file plot.wls
```

Після виконання скрипта у поточній директорії з'явиться файл benchmark_chart.png (діаграма з логарифмічною шкалою часу).
