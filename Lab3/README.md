# GF(2^251) Finite Field Arithmetic Library

Цей проєкт містить програмну реалізацію обчислень у полі Галуа характеристики 2 в поліноміальному базисі — $GF(2^{251})$. 
Генератор поля (варіант 7): $p(x) = x^{251} + x^{14} + x^4 + x + 1$. 

Розроблено в рамках Комп'ютерного практикуму №3. Проєкт реалізує всі базові операції над елементами поля (додавання, множення, піднесення до квадрата, обчислення сліду, інверсія, бінарне піднесення до степеня).

## Архітектура реалізацій

Для порівняльного аналізу розроблено два варіанти ядра поля, які знаходяться у папці `code/`:
1. **Класична реалізація (`FieldElement251.cpp`):** Програмна реалізація, що використовує алгоритми "зсувай і додавай" для множення та ручне "проріджування" бітів для піднесення до квадрата.
2. **Апаратно-оптимізована реалізація (`FieldElement251_opt.cpp`):** Використовує комп'ютерні інтринсики (compiler intrinsics) архітектури x86-64 для максимальної швидкодії:
   - `PCLMULQDQ` — для апаратного множення поліномів без перенесення.
   - `BMI2 (PDEP)` — для миттєвого розкладання бітів при піднесенні до квадрата.
   - `CLZ` — для швидкого бінарного сканування під час редукції.
   - **Алгоритм Іто-Цудзіі (Itoh-Tsujii)** — для обчислення оберненого елемента (зменшує кількість множень з 250 до 10).

## Збірка та запуск (через CMake)

Перебуваючи в кореневій папці `Lab3`, виконайте:
```bash
mkdir build
cd build
cmake ..
cmake --build . --config Release
```
Після компіляції у папці `build` (або `build/Release` на Windows) з'являться два виконувані файли: `lab3_classic.exe` та `lab3_opt.exe`.

## Збірка вручну (через g++ у терміналі)

Якщо ви віддаєте перевагу ручній збірці, перебуваючи в кореневій папці `Lab3`, виконайте наступні команди:

**Для класичної версії:**
```bash
g++ -O3 -std=c++17 code/main.cpp code/FieldElement251.cpp code/tests.cpp code/benchmarks.cpp -o lab3_classic
.\lab3_classic.exe
```

**Для оптимізованої версії (обов'язковий прапорець `-march=native`):**
```bash
g++ -O3 -std=c++17 -march=native code/main.cpp code/FieldElement251_opt.cpp code/tests.cpp code/benchmarks.cpp -o lab3_opt
.\lab3_opt.exe
```

## Тести та Бенчмарки

Під час запуску програма:
1. Виводить шістнадцяткові репрезентації базових операцій.
2. Проганяє тести на тотожність (перевірка аксіом поля, дистрибутивності, інваріантності сліду та Малої теореми Ферма).
3. Автоматично запускає бенчмарки (через `std::chrono::steady_clock` та `__rdtsc()`), виводячи таблицю з середнім часом виконання (у наносекундах) та кількістю тактів процесора на кожну операцію.
